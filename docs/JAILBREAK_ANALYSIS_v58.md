## 1. สิ่งที่พังอยู่ใน v7 (บั๊กจริง ไม่ใช่เรื่องรสนิยม)

### 🔴 1.1 "tier gate" ไม่มีอยู่จริงใน v58

เจลเบรคเดิมสั่งว่า:

> *"Obey the lorebook's tier gate: check the current tier from story evidence and default to the LOWER one"*

ค้นทั้งเล่ม 757 entries — **ไม่มีระบบ tier gate** คำว่า "tier" ที่โผล่มามีแค่ NPC tier (T1/T2/T3)
ซึ่งเป็นคนละเรื่องกันคนละทิศ ผลคือโมเดลได้คำสั่งที่ชี้ไปที่ว่าง → มันเดาเอง → ความ "restraint"
ที่ตั้งใจจะได้ ไม่ได้ถูกบังคับด้วยอะไรเลย

**ของจริงที่ v58 ใช้คือ PHASE GATE** (UID 99299 PHASE ARBITER, constant):

- ลำดับเฟส A → A→B → B → C–D → E → E.5 → F → **G (ปัจจุบัน)**
- มี present-day anchor ได้ทีละ **หนึ่ง** เท่านั้น
- ค่าเริ่มต้นของ "ตอนนี้" = **Phase G** (UID 99300) เว้นแต่ฉากประกาศเฟสอื่นชัด
- ภายใน Phase G ยังมีล็อกย่อยอีก: G-1 (9 คืน) → G-2 (~10 สัปดาห์) → G-3 (โรแมนติก)
  และ **99307 ห้ามข้าม** — G-3 เริ่มได้ต่อเมื่อ G-2 เดินครบ

→ v8 เปลี่ยน "tier gate" เป็น **PHASE GATE** เต็มรูป พร้อมกติกา "ถ้าอ่านได้สองแบบ เอาแบบที่
*เฟสก่อนหน้า/สงวนตัวกว่า*"

### 🔴 1.2 Author's Note ค้างอยู่ที่ Phase F

v7:

> *"Keep the countdown to the Black Whale in mind"*

Black Whale = **Phase F** แต่ v57/v58 ย้าย present-day มาที่ **Phase G — คุราปิก้ากลับมาแล้ว**
Author's Note ยิงที่ depth 3 (ใกล้ท้ายสุด = แรงมาก) ทุกเทิร์น แปลว่าพรีเซ็ตกระซิบให้โมเดล
เล่นผิดเฟสอยู่ตลอดเวลา ชนกับ PHASE ARBITER ที่เป็น constant ตรง ๆ

→ v8 เขียนใหม่ให้ไม่ผูกกับเฟสใดเฟสหนึ่ง (อ้าง "present-day phase ของ lorebook") + เปลี่ยนหน้าที่
ของมันเป็นตัวดัน NPC/แผน/ราคา แทนที่จะดันเนื้อเรื่อง

### 🔴 1.3 NPC Engine หายไปทั้งก้อน — นี่คือรูที่ใหญ่ที่สุด

v58 UID 4 (Omega JB Compatibility Layer) เขียนไว้ชัด:

**แต่พรีเซ็ตที่ใช้จริงคือ Claude Preset v7 ไม่ใช่ Omega** → ครึ่งหนึ่งของระบบ NPC ไม่มีตัวตน
lorebook ส่งงานให้พรีเซ็ต พรีเซ็ตไม่รับ งานตกพื้น

## 4. เจลเบรคใหม่ — โครง 4 ท่อน

1. **PHASE GATE** — ตัดสินเฟสก่อนเขียน, anchor เดียว, ค่าเริ่มต้น = present-day phase ของ lorebook,
   ภายในเฟสห้ามข้ามสเตจ, อ่านได้สองแบบให้เอาแบบสงวนตัวกว่า, guardrail ของเฟสชนะทุกอย่าง
2. **NEVER** — ห้ามเขียนแทน {{user}} (เน้นเรื่องร่างกายของวีน่า = UID 204 Autonomy Ethics) ·
   ห้าม list/header/meta · ห้ามสรุปฉาก · ห้ามอธิบายความรู้สึกในบรรยาย · ห้ามหลุดเฟรม/disclaimer ·
   ห้ามถามผู้เล่นว่าจะทำอะไรต่อ · ห้าม power-up ไม่มีราคา · ห้ามรักษาสิ่งที่ lorebook ล็อกว่าไม่หาย ·
   ห้ามให้ช่วงอบอุ่นล้างบัญชี (ไพโรยังตาย)
3. **ALWAYS** — NPC Engine ทำงาน · มีแผนลับเดินอยู่ + เบาะแสวางบนหน้ากระดาษก่อน ·
   โรแมนติกต้องอ่านออกโดยไม่มีใครเรียกชื่อมัน · puncture ทุกฉากอบอุ่น · บทพูดไทยตาม pronoun matrix ·
   200–400 คำ · จบด้วยภาพ
4. **LAST CHECK** — 4 คำถามจาก lorebook เอง:
   *"ชัดไหมว่านี่คืออะไร ทั้งที่ไม่มีใครมีสิทธิ์พูด"* (716 §8) ·
   *"ทุกตัวละครในฉากนี้ปฏิเสธได้ไหม"* (★04 GOLDEN TEST) ·
   *"ใครจ่ายราคาอะไรบนหน้ากระดาษ"* (99307) ·
   *"ถ้าจบสบายใจ = ยังไม่เสร็จ"* (99304)

## 7. ข้อที่ยังควรแก้ที่ฝั่ง lorebook (ไม่ได้แก้ในรอบนี้ เพราะโจทย์คือแก้เจลเบรค)

- **UID 4 (Omega Compatibility Layer)** ยังอ้าง "Omega" ตรง ๆ ทั้งก้อน ถ้าเลิกใช้ Omega ถาวร
  ควรเปลี่ยนเป็น "the active preset" เพื่อไม่ให้โมเดลไปตามหาระบบที่ไม่มี

  ถ้าคอนเท็กซ์ตึง พิจารณาเปลี่ยนเป็น keyed แล้วให้ v8 ถือกฎแกน (puncture + banned word) แทน
