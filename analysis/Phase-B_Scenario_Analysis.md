## 3) ⚠️ จุดที่ "ขัดกับ canon" — ต้องตัดสินใจก่อนเล่น

### ⚠️ #1 (สำคัญที่สุด) — "วีน่ารู้ไหมว่าตัวเองเป็นคู่หมั้น?"

**ร่างฉากของคุณ + การ์ด `Killua_EDITED`:** วีน่า **ไม่รู้** ว่าตัวเองเป็นคู่หมั้น (การ์ดเขียน "Vina's *secret* fiancé") → เธอบอกว่า "เราเป็นเพื่อนกัน" เพราะไม่รู้ / เธอคิดว่าคิลัวรู้เรื่องสัญญา 2 ปีอยู่แล้ว

**Lorebook เล่มใหญ่ (idx 33 §102d + idx 45):** วีน่า **รู้** — canon เขียนชัด:
- idx 45: *"Vina, the same age, mirrored him with deadpan disdain"* (เธอเมินสัญญาหมั้นแบบเย็นชาเหมือนคิลัว)
- idx 33 §102d: *"วีน่า — รู้ว่ามันคือกรงอีกชั้นของพ่อบุญธรรม ไม่ใช่เรื่องของหัวใจใคร"*

👉 **นี่คือข้อขัดแย้งจริง** ระหว่างเอกสารของคุณเอง 2 ชุด ต้องเลือก 1 อย่าง:
- **ทางเลือก A (ตามร่างฉาก/การ์ด EDITED):** วีน่าไม่รู้ → dramatic irony สองชั้น (คิลัวคิดว่าเธออยู่ตลอดไป / เธอคิดว่าเขารู้ว่าแค่ 2 ปี / ทั้งคู่ไม่รู้ว่าอีกฝ่ายเข้าใจคนละเรื่อง). **ดราม่ากว่า** แต่ต้อง **แก้ lorebook idx 33 §102d และ idx 45** ให้เป็น "วีน่าไม่รู้เรื่อง engagement clause"
- **ทางเลือก B (ตาม lorebook):** วีน่ารู้ว่ามันคือ "กรงกระดาษ" แต่ไม่แคร์ → ทั้งคู่รู้ทั้งคู่เมิน. ต้องแก้ **การ์ด EDITED + ร่างฉาก** ให้เธอรู้

*(แนะนำ A ถ้าอยากได้ dramatic irony ที่คุณตั้งใจ — แต่ต้องยอมแก้ 2 entry ใน lorebook ให้ตรงกัน ไม่งั้นโมเดลจะสับสนเพราะอ่านทั้งสองแบบพร้อมกัน)*

### ⚠️ #2 — "คิลัวไม่รู้ว่าสัญญาแค่ 2 ปี / คิดว่าวีน่าจะอยู่ตลอดไป"

- **Canon (idx 45/631):** การจากลาเป็น **แบบกะทันหัน** — "สัญญาครบ 2 ปี → Wendric สั่งลากวีน่ากลับทันที ไม่มีเวลาบอกลา" แล้วคิลัวถึงหนีตามทีหลัง. lorebook **ไม่ได้ระบุ** ว่าคิลัวรู้/ไม่รู้ล่วงหน้าว่าแค่ 2 ปี
- ร่างของคุณเพิ่ม motivation ว่า "คิลัวไม่รู้ เลยคิดว่าเธอจะอยู่ตลอดไป (โดนขังด้วยกัน/หนีไปด้วยกัน)" → **เข้ากันได้ ไม่ขัด** และช่วยอธิบายว่าทำไมตอนเธอถูกลากกลับเขาถึงพัง แต่ควร **เขียนเพิ่มให้ชัด** ใน lorebook ว่า "คิลัวไม่เคยอ่าน/ไม่รู้ระยะเวลาสัญญา" เพราะตอนนี้ canon เงียบเรื่องนี้

### ⚠️ #3 — สถานะวีน่า: "แขกร่วมฝึก" หรือ "ของเล่น/ทรัพย์สิน"?

- **ร่างของคุณ:** วีน่า = "แขกร่วมฝึก" (guest) แต่ต้องทำตามกฎบ้าน
- **Canon idx 631:** *"สถานะทางการของวีน่าในบ้าน Zoldyck = 'ของเล่นของคิลัว' — ตระกูลจัดหมวดเธอเป็นทรัพย์สินฝึกหัด **ไม่ใช่แขก**"* (การ์ด EDITED ก็ใช้ "porcelain doll / burden")
- 👉 คำว่า "แขก" ทำให้ power dynamic อ่อนลงมาก (แขก = มีสิทธิ์-มีเกียรติ / ของเล่น = ถูกใช้เป็นคานงัดลงโทษแทนคิลัวได้). **แนะนำใช้คำ canon:** เธอถูกจัดเป็น "ทรัพย์สินฝึก/ของเล่นของคิลัว" ในสายตาตระกูล — ส่วนคำว่า "แขก" ใช้ได้แค่ในความรู้สึกของวีน่าเอง/สิ่งที่ Surilvan บอกเธอ ไม่ใช่สถานะจริงในบ้าน Zoldyck

### ⚠️ #4 — คิลัวแอบฟัง "**Zeno** กับ Silva" คุยกัน

- **Canon:** คนเซ็น/คุยเรื่องสัญญาคือ **Silva ↔ Wendric** (ปู่ Zeno ไม่ได้อยู่ในดีลนี้). การ์ด EDITED เขียนว่า "overheard the adults"
- 👉 เล็กน้อย: ถ้าจะให้คิลัวแอบฟัง ควรเป็น **Silva (+ Wendric/Kikyo)** เพื่อให้ตรง ถ้ายืนยันจะใช้ Zeno ก็ได้แต่เป็นการเพิ่มใหม่ (Zeno ไม่ได้เกี่ยวกับสัญญาใน canon)

### ⚠️ #5 — บุคลิกวีน่า: "โวยวายเด็กๆ" vs "โหมดประหยัดพลัง เดดแพน"

- **ร่างของคุณ:** วีน่า "ทะเลาะ + โวยวายแบบเด็กๆ"
- **Canon idx 21:** default = *"low-power, lazy posture, sleepy face, brief words"* + ตลกร้ายเดดแพน; อารมณ์พุ่งเป็น *"tsundere possessive"* ("ถ้าฉันอยากได้ ฉันต้องได้")
- 👉 ไม่ถึงกับขัด แต่ **โทนต่างกัน**: canon วีน่าไม่ใช่เด็กจอมโวยวายเสียงดัง เธอคือเด็ก **ขี้เกียจ-เนือย-ปากร้ายเบาๆ** ที่ระเบิดเป็นหวงของ/เอาแต่ใจเป็นครั้งคราว. "โวยวาย" ที่ตรง canon = บ่นจุกจิก (ห้องรก/แย่งขนม) ไม่ใช่กรี๊ดกร๊าด. ระวังอย่าให้กลายเป็น genki girl

## 4) ➕ จุดที่ "เพิ่มใหม่" — ไม่มีใน canon แต่เข้ากันได้ (ใส่ได้ ถ้าอยากให้เป็น canon ก็ควรบันทึกเพิ่ม)

1. **"ถ้าคิลัวไม่รับวีน่าเป็นคู่หมั้น คู่หมั้นอาจเป็นอิรุมิหรือมิลลูกิ"** — เป็นเหตุผลที่ดีว่าทำไมคิลัวต้อง "รับผิดชอบ" เธอเอง. lorebook **ไม่ได้ระบุ** ทางเลือกนี้ (canon: สัญญาระบุคิลัวเจาะจง, Kikyo ขอเพิ่มวีน่าเพื่อทดลอง). การ์ด EDITED มีแค่ใบ้ว่ามิลลูกิเป็น "ภัย" ที่คิลัวกันออก → ข้อนี้ **เพิ่มได้** แต่ควรจดเป็น entry ใหม่ ("ทำไมคิลัวต้องเป็นคนรับผิดชอบ") ไม่งั้นจะลอย
2. **เศษผ้าที่คิลัวฉีกพันแผลแล้วห้ามทิ้ง** — canon มี "ของขวัญอำลา" แต่เป็น **วีน่า→คิลัว** (idx 45 THE LAST MORNING). ทิศของคุณคือ **คิลัว→วีน่า** (เศษผ้า) → เป็นของใหม่ที่ **เสริมกันได้ดี** (ต่างชิ้น ต่างทิศ ไม่ชนกัน)
3. **Surilvan ตามใจวีน่าทุกอย่าง ยกเว้นภารกิจ/หน้าที่** — canon วาด Wendric/Surilvan เป็นฝ่าย **ควบคุม** ("เวลาของเธอถูกยึดเสมอ", ทดลองออร่า, บังคับกินยา). ประนีประนอมได้: **บ้าน/คนรับใช้ Surilvan ตามใจเธอเรื่องวัตถุ** (เงิน/ของเล่น/สั่งทำอาวุธ — ซึ่งอธิบายว่าทำไมเธอสั่งของ exclusive ให้คิลัวได้ฟรี) **แต่ Wendric คุมภารกิจ/หน้าที่/ร่างกายเธอเบ็ดเสร็จ**. เขียนแยกสองชั้นนี้จะไม่ขัด canon
