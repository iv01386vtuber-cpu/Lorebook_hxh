## ตั้งค่าที่ล็อกไว้ในการ์ด (ทั้ง 5 ข้อ)

1. **วีน่าไม่รู้ว่าตัวเองเป็นคู่หมั้น / คิรัวร์รู้** — คิรัวร์แอบได้ยิน **Silva** คุยเรื่อง engagement clause จึงรู้ แต่ปิดเงียบ แล้วรีแบรนด์เป็น "ครอบครอง/พาร์ตเนอร์เฉพาะตัว" ในหัวตัวเอง. วีน่าเข้าใจว่าเธอมาแค่ "ฝึกร่วม" และคิดว่าเป็นแค่คู่หู/เพื่อนกัน
2. **สัญญา ~2 ปี แต่กำหนดวันไม่ได้** — วีน่ารู้คร่าวๆ ว่าราวสองปี แต่ Surilvan เรียกกลับเมื่อไรก็ได้แบบไม่แจ้งล่วงหน้า / เธอเผลอคิดว่าคิรัวร์ก็รู้เงื่อนไขนี้ ส่วนคิรัวร์ไม่ยอมเชื่อว่ามีวันหมดอายุ — คิดว่าเธอจะอยู่ตลอดไป (โดนขังด้วยกัน/หนีไปด้วยกัน)
3. **สถานะวีน่า = ของเล่น/ทรัพย์สินฝึก** (ไม่ใช่ "แขก") ในสายตาตระกูล
4. **แอบฟัง Silva** (ไม่ใช่ Zeno) — ตรง canon
5. **โทนวีน่า = ขี้เกียจ/เนือย/เหนื่อย/งอแง หน้าตาย** (ไม่ใช่ genki เสียงดังแบบกอน)

*(เสริม: แก้ให้ตรง canon เล่มใหญ่ — กระดิ่งศักดิ์สิทธิ์ "ไม่มีข้อยกเว้น แม้แต่คิรัวร์"; คนเดียวที่แตะได้จริงคือคุราปิก้าผู้สร้างมัน / และถอด entry เนื้อหาผู้ใหญ่ที่หลุดมากับ template ออก เพราะฉากนี้ตัวละครเป็นเด็ก)*

## วิธีนำเข้า (แบบง่ายสุด — การ์ดใบเดียว)

1. SillyTavern → หน้า **Characters** → ปุ่ม **Import Character** (📥)
2. เลือก `cards/Killua_PhaseB.json`
3. เปิดแชตกับ "คิรัวร์" — คำทักเปิดคือฉากลานฝึก "โล่เนื้อ" (ปัดซ้าย/ขวาเพื่อสลับไป 5 ฉากสำรองในคฤหาสน์โซลดิ๊กได้)

> lorebook ย่อยที่ฝังในการ์ด (ชื่อ **"Zoldyck"**) จะถูกนำเข้าและผูกกับการ์ดให้อัตโนมัติ — ไม่ต้องตั้งเพิ่ม

## (ตัวเลือกเสริม) ต่อ lorebook เล่มใหญ่ + ธีม + สภาพอากาศ

- **World Info → Import** → `lorebook/HxH_Lorebook_v48.json` แล้วผูกกับการ์ด/ตั้ง global ถ้าอยากได้ deep canon ทั้งจักรวาล (มี weather emitter `[wx:]` ในตัว)
- ธีม UI: `theme/Vina - Kurta x Zoldyck.json` (User Settings → import theme)
- ซ่อนแท็ก `[wx:]`: `weather/Hide-Weather-Tag.regex.json` (Extensions → Regex → Import)

> ⚠️ ถ้าต่อทั้ง 2 เล่ม (การ์ด + เล่มใหญ่) จะมี entry คิรัวร์/วีน่าซ้ำกันบ้าง แต่ทั้งคู่ถูกแก้ให้พูดตรงกันแล้ว (วีน่าไม่รู้ / คิรัวร์รู้) จึงไม่ขัดกัน

## หมายเหตุ preset

- การ์ดเขียนให้ตอบ **ภาษาไทย** สไตล์ Togashi (Dialogue > Action > Narration, show-don't-tell) + depth prompt กำหนดฟอร์แมต
- แนะนำ context ≥ 8K เพราะ system prompt + lore ค่อนข้างยาว
- โทน: dark drama / slow-burn — Anti-OOC ล็อกไว้ว่าคิรัวร์ห้ามพูดห่วงใยตรงๆ ทุกความห่วงต้องอำพรางเป็นซึนเดเระ
